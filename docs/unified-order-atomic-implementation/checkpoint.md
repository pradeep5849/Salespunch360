# A127-F02 — Atomic unified order creation/enrichment

Web/native unified order creation now finalizes the Telecaller target in the base-order transaction under the company billing lock. The order amount and marker commit together with the base order/audit. Pending-order reuse finalizes under the same lock; an order row lock serializes marker checking/increment, and a saved marker returns the unchanged total. The quote reads through that transaction client. Web idempotent retries can read the target from the base creation audit when repairing an older incomplete pending order. Cancelled/paid legacy orders are not recharged or reopened; historical duplicates/undercharges are not automatically rewritten.
