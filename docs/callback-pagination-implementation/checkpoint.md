# A164-F02 — Complete scheduled-call queue paging

Web and current Android clients use one server-paged union of callback history and pending Telecaller Call tasks. Visibility and entitlement filters apply before paging. Stable due-date, ID and source ordering spans both sources; no 100-display/500-source cap hides later results. Existing Overdue/Today/Upcoming groups and date-only task policy remain. Counts explicitly describe the current page; Previous/Next retain the web search. Android preserves the current page on refresh/save and retains rows on fetch failure. Legacy unpaged mobile requests retain their prior response shape for compatibility.
