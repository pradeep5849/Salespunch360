# A153-F01 — Complete-day attendance card history

Sales attendance cards and an Admin's selected-employee history now page by seven India calendar days, rather than splitting sessions by a row page. Every matching session of a displayed day is included before duration, GPS-count and route-distance totals are presented. Web and Android show the page's date window with Previous/Next; older pages open past attendance and omit the misleading empty Today summary. Web links retain dates, employee, status and branch. Team overview retains row paging; summary totals remain scoped to the full selected range. XLSX retains full-range row export and its explicit 10,000-row ceiling, including the Sales default date range. A history window above 10,000 sessions raises an explicit narrowing error instead of silently presenting a partial day. Sessions retain the existing grouping by their India start date; overnight allocation policy is unchanged.
